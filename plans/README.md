## Recommended execution order

1. **001, 002, 003** — independent of each other and of everything else
   (different files: `heart_particles.dart`, `spiral_painter.dart`,
   `splash_screen.dart`). Safe to run in any order, including in parallel.
2. **004** — independent (`animated_button.dart` only). Safe anytime.
3. **005** — must run before 006 if both are applied, since 006's
   `home_screen.dart` change layers a `reducedMotion` ternary onto whatever
   variable holds the erratic scale multiplier after 005's rewrite. See the
   explicit note in plan 006's Boundaries section.
4. **006** — depends on 005 having been applied first (see above). Also
   touches `glitch_text.dart` and `heart_particles.dart`; the
   `heart_particles.dart` portion is independent of plan 001 but touches
   the same file, so apply 001 first to avoid re-deriving diff context.
5. **007** — independent of 001-006 in terms of correctness, but touches
   `home_screen.dart` and `share_preset_sheet.dart`. If 005/006 have
   already modified `home_screen.dart`, apply 007 after them to avoid merge
   conflicts in the same file (the changes don't overlap in content, just
   proximity).
6. **008** — fully independent (`badges_screen.dart` only, a file no other
   plan touches). Safe anytime.

**Suggested sequential order for `execute`**: 001 → 002 → 003 → 004 → 005 →
006 → 007 → 008 (dependency-respecting; matches the audit's severity
ranking).
